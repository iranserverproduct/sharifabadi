# تحلیل محصول و بازار: گیت‌وی مدیریت‌شده‌ی هوش مصنوعی (AI Gateway) روی زیرساخت خارج ایران‌سرور

**تاریخ:** ۱۳ آبان ۱۴۰۵ (2026-11-03)
**هدف:** تصمیم‌گیری درباره‌ی اضافه کردن یک «گیت‌وی هوش مصنوعی» به برنامه‌های آماده‌ی ایران‌سرور (فقط روی دیتاسنتر خارج)، و انتخاب نرم‌افزار مناسب برای بازار ایران
**روش:** Apify (YouTube Search Scraper، Google Trends Scraper، RAG Web Browser)، آمار عمومی npm، Docker Hub، GitHub و Railway، بررسی مستندات و Dockerfile نرم‌افزارها، و جستجوی وب.
**محدودیت داده:** اعتبار Apify حدود ۰٫۳۶ دلار بود و اجرای Google SERP رد شد. آمار رسمی تعداد برنامه‌نویسان ایران در ۱۴۰۴ پیدا نشد، پس عددهای حجم بازار **تخمینی** هستند. هیچ‌کدام از نرم‌افزارها روی کلاستر واقعی اجرا نشد.

> **ساختار گزارش:** بخش‌های ۱ تا ۴ خود محصول را معرفی می‌کنند، مستقل از هر نرم‌افزار خاص. بخش‌های ۵ تا ۷ بازار را تحلیل می‌کنند. بخش ۸ نرم‌افزارهای موجود را با معیارهایی که از بخش‌های قبل به دست آمده مقایسه می‌کند و انتخاب نهایی را نتیجه می‌گیرد.

---

## خلاصه‌ی مدیریتی

- **محصول:** یک «سوئیچ مرکزی» برای مدل‌های هوش مصنوعی. کاربر به‌جای اینکه هر ابزار (Claude Code، Cursor، n8n و...) را جدا به هر ارائه‌دهنده وصل کند، همه را به **یک آدرس** روی سرور خارج وصل می‌کند. گیت‌وی تصمیم می‌گیرد هر درخواست به کدام مدل و کدام حساب برود. اگر یکی جواب نداد، سراغ بعدی می‌رود و مصرف را هم گزارش می‌کند.
- **نیاز اصلی در ایران قوی است.** دسترسی ارزان و پایدار به مدل‌های کدنویسی موضوع داغی است: ویدیوهای فارسی «Claude Code رایگان» ۷۳ تا ۹۶ هزار بازدید دارند، و ایران در Google Trends جزو سه کشور اول در علاقه به این ابزارهاست.
- **تقاضای پولی برای نسخه‌ی میزبانی‌شده کوچک ولی واقعی است.** هسته‌ی این ابزارها رایگان است و روی لپ‌تاپ نصب می‌شود. ارزش نسخه‌ی مدیریت‌شده در این‌هاست:
  - همیشه روشن است و برای تیم مشترک است
  - روی IP خارجی اجرا می‌شود
  - پرداخت ریالی دارد
  - پشتیبانی فارسی دارد
  - نصب و نگهداری ندارد
- **پیش‌بینی استقبال:** از نظر درآمد متوسط تا کم (SOM سال اول حدود ۶ تا ۱۸ هزار دلار)، ولی **به‌عنوان قیف جذب و فروش افزایشی خوب است**. هزینه‌ی فنی ورود کم است.
- **انتخاب نرم‌افزار (نتیجه‌ی بخش ۸):** برای پلن پایه‌ی بازار ایران، **9Router** بالاترین امتیاز را گرفت (۸۶ از ۱۰۰). دلیل‌ها: سبک است، داشبورد فارسی دارد و آشنایی بازار ایران با آن بیشتر است. **OmniRoute** (۷۴) کاندیدای پلن حرفه‌ای و تیمی است. **new-api** (۶۷) برای یک محصول B2B جداگانه در آینده مناسب است. LiteLLM و claude-code-router با ساختار برنامه‌های آماده سازگار نیستند.

## ۱. محصول چیست؟

### تعریف
**گیت‌وی هوش مصنوعی** (که به آن AI Gateway، LLM Router یا LLM Proxy هم می‌گویند) یک سرویس واسط است که بین ابزارهای کاربر و ارائه‌دهنده‌های مدل‌های زبانی قرار می‌گیرد. خودش مدل AI نیست و چیزی تولید نمی‌کند. کارش این است که **درخواست را بگیرد، تصمیم بگیرد کجا برود، به فرمت درست ترجمه کند، بفرستد و پاسخ را برگرداند.**

**تشبیه ساده:** مثل یک مودم‌روتر برای اینترنت خانه. همه‌ی دستگاه‌ها به یک روتر وصل می‌شوند و روتر ترافیک را مدیریت می‌کند. اینجا همه‌ی ابزارهای AI به یک گیت‌وی وصل می‌شوند و گیت‌وی بین ده‌ها ارائه‌دهنده مسیریابی می‌کند.

```text
 ابزارهای کاربر                    گیت‌وی (سرور خارج ایران‌سرور)             ارائه‌دهنده‌های مدل
┌──────────────┐                 ┌──────────────────────────────┐        ┌────────────────────┐
│ Claude Code  │──┐              │  • احراز هویت با کلید API      │   ┌──▶│ اشتراک‌ها (OAuth)   │
│ Cursor/Cline │──┤              │  • انتخاب مدل و حساب           │   │   │ Claude/Codex/...   │
│ n8n / ایجنت  │──┼──▶ یک آدرس ──▶│  • ترجمه‌ی فرمت (OpenAI/Claude) │───┼──▶│ کلیدهای API         │
│ اپلیکیشن شما │──┘   /v1        │  • fallback و تعویض حساب       │   │   │ DeepSeek/GLM/...   │
└──────────────┘                 │  • ثبت مصرف و هزینه            │   └──▶│ تیرهای رایگان       │
                                 └──────────────────────────────┘        └────────────────────┘
```

### نسخه‌ی «مدیریت‌شده» چه فرقی دارد؟
هسته‌ی نرم‌افزار متن‌باز و رایگان است. ایران‌سرور این کارها را انجام می‌دهد:
- نصب با یک کلیک در پنل
- دامنه و SSL
- به‌روزرسانی امنیتی
- بکاپ
- منابع قابل‌افزایش
- پشتیبانی فارسی
- **اجرا روی دیتاسنتر خارج**، یعنی درخواست‌ها از IP غیرایرانی به ارائه‌دهنده‌ها می‌روند
- پرداخت ریالی

## ۲. امکانات برای کاربر نهایی

امکانات مشترک این دسته از محصولات، صرف‌نظر از اینکه کدام نرم‌افزار انتخاب شود:

| گروه | امکان | ارزش برای کاربر |
|---|---|---|
| **اتصال یکپارچه** | یک endpoint سازگار با OpenAI (و معمولاً Claude و Gemini) روی `/v1` | هر ابزاری که «Base URL سفارشی» بپذیرد وصل می‌شود؛ کاربر تنظیمات را یک‌بار انجام می‌دهد |
| | اتصال به ده‌ها ارائه‌دهنده با **کلید API** | DeepSeek، GLM، Kimi، OpenRouter، Groq و... همه در یک جا |
| | اتصال به **اشتراک‌های شخصی** (Claude Pro/Max، ChatGPT Plus، Copilot) با OAuth | از اشتراکی که خریده‌اید در ابزارهای دیگر هم استفاده کنید. ⚠️ با شرایط استفاده‌ی برخی ارائه‌دهنده‌ها مغایر است |
| | تیرهای رایگان | شروع بدون هزینه با مدل‌های رایگان (فهرستش مدام عوض می‌شود) |
| **مسیریابی و پایداری** | **Fallback خودکار** | وقتی سهمیه‌ی یک مدل تمام شد یا خطا داد، درخواست بی‌وقفه به مدل یا حساب بعدی می‌رود |
| | **Combo** یا زنجیره‌ی مدل | مثلاً اول اشتراک، بعد API ارزان، بعد رایگان |
| | چند حساب برای هر ارائه‌دهنده | پخش بار بین حساب‌ها و دور زدن محدودیت نرخ |
| | ترجمه‌ی فرمت | ابزاری که فقط فرمت Claude را می‌فهمد می‌تواند از مدل OpenAI یا DeepSeek استفاده کند |
| **هزینه و مصرف** | داشبورد مصرف: توکن، درخواست، هزینه‌ی تخمینی، سهمیه‌ی باقی‌مانده | کاربر می‌داند پولش کجا می‌رود و کی سهمیه ریست می‌شود |
| | فشرده‌سازی توکن (در برخی نرم‌افزارها) | ۲۰ تا ۴۰٪ صرفه‌جویی در توکن ورودی، طبق ادعای سازندگان |
| **تیم و امنیت** | ساخت **کلید API جدا** برای هر عضو تیم یا ابزار | لغو دسترسی یک نفر بدون عوض کردن کلید اصلی ارائه‌دهنده |
| | نگه‌داری کلیدهای اصلی فقط روی سرور | کلیدهای گران‌قیمت روی لپ‌تاپ اعضای تیم پخش نمی‌شود |
| | سقف مصرف و کاربر چندگانه (در برخی نرم‌افزارها) | کنترل هزینه‌ی تیم |
| **دسترسی‌پذیری** | اجرا روی سرور خارج و همیشه روشن | از هر دستگاه و هر جا، بدون نیاز به VPN روی دستگاه کاربر؛ مناسب ایجنت‌های ۲۴ ساعته |

## ۳. کاربر نهایی کیست و می‌خواهد به چه برسد؟

### پرسوناها
| پرسونا | وضعیت فعلی | درد اصلی | هدف |
|---|---|---|---|
| **۱. برنامه‌نویس فریلنسر یا مستقل** | از Claude Code، Cursor یا OpenCode با VPN و حساب‌های پراکنده استفاده می‌کند | سهمیه وسط کار تمام می‌شود؛ VPN قطع و وصل می‌شود؛ پرداخت ارزی سخت است | کدنویسی بی‌وقفه با کمترین هزینه |
| **۲. تیم نرم‌افزاری یا استارتاپ (۳ تا ۲۰ نفر)** | هر نفر کلید و اشتراک خودش را دارد؛ هزینه نامعلوم است | کلیدها پخش شده‌اند؛ هزینه کنترل نمی‌شود؛ هر نفر تنظیمات جدا دارد | یک نقطه‌ی مرکزی با کلید جدا برای هر نفر و گزارش هزینه |
| **۳. سازنده‌ی ایجنت و اتوماسیون** (n8n، OpenClaw، Hermes) | ایجنت روی سرور اجرا می‌شود و به مدل نیاز دارد | ایجنت باید ۲۴ ساعته کار کند؛ قطعی یک ارائه‌دهنده کل فرایند را می‌خواباند | backend پایدار و همیشه‌روشن با fallback |
| **۴. توسعه‌دهنده‌ی محصول AI** (چت‌بات، اپ) | اپلیکیشنش به LLM وصل است | وابستگی به یک ارائه‌دهنده؛ تحریم؛ تغییر قیمت | جدا کردن اپ از ارائه‌دهنده؛ عوض کردن مدل بدون تغییر کد |

### کارهایی که کاربر می‌خواهد انجام دهد (Jobs to be Done)
- «**وقتی** وسط کدنویسی سهمیه‌ی مدلم تمام می‌شود، **می‌خواهم** درخواست خودکار به مدل دیگری برود **تا** کارم متوقف نشود.»
- «**وقتی** از ایران به ارائه‌دهنده‌های خارجی وصل می‌شوم، **می‌خواهم** دسترسی پایدار و بدون دردسر VPN داشته باشم **تا** وقتم صرف دور زدن محدودیت نشود.» گزارش Quera می‌گوید حدود ۱۰٪ زمان کاری برنامه‌نویسان ایرانی صرف همین کار می‌شود.
- «**وقتی** چند ابزار AI دارم، **می‌خواهم** همه را یک‌بار تنظیم کنم **تا** با تغییر مدل یا کلید مجبور نباشم همه‌جا را عوض کنم.»
- «**وقتی** تیمم از AI استفاده می‌کند، **می‌خواهم** بدانم هر نفر چقدر مصرف کرده **تا** هزینه را کنترل کنم.»
- «**وقتی** ایجنتم شبانه‌روز کار می‌کند، **می‌خواهم** گیت‌وی همیشه روشن باشد **تا** لپ‌تاپم مجبور نباشد روشن بماند.»

### هدف نهایی کاربر
**استفاده‌ی پیوسته، ارزان و بی‌دردسر از بهترین مدل‌های AI در کارهای روزمره (به‌خصوص کدنویسی)، بدون اینکه درگیر محدودیت‌ها، قطعی‌ها و پراکندگی حساب‌ها شود.** خود گیت‌وی هدف نیست؛ ابزاری برای رسیدن به «کدنویسی بی‌وقفه» و «کنترل هزینه» است.

## ۴. فلوی کار با محصول

### الف) فلوی کاربر نهایی
```text
خرید در پنل ─▶ ساخت خودکار ─▶ اولین ورود ─▶ اتصال ارائه‌دهنده‌ها ─▶ ساخت Combo ─▶ ساخت کلید API ─▶ اتصال ابزارها ─▶ استفاده‌ی روزانه ─▶ پایش مصرف
```

| مرحله | کاربر چه می‌کند | چه می‌بیند یا چه اتفاقی می‌افتد | نکته‌ی پشتیبانی |
|---|---|---|---|
| **۱. خرید** | در پنل ایران‌سرور پلن (شخصی یا تیمی) را انتخاب می‌کند و ریالی پرداخت می‌کند | – | – |
| **۲. ساخت** | منتظر می‌ماند (حدود ۱ تا ۲ دقیقه) | آدرس داشبورد (مثلاً `https://name.app.iranserver...`) و رمز اولیه | ArgoCD کانتینر، والیوم و Ingress را می‌سازد |
| **۳. اولین ورود** | وارد داشبورد می‌شود و رمز را عوض می‌کند | داشبورد خالی با منوی Providers، Combos، Keys و Usage | رمز اولیه باید تصادفی باشد |
| **۴. اتصال ارائه‌دهنده‌ها** | **با کلید API:** کلید DeepSeek، OpenRouter و... را paste می‌کند. **با اشتراک (OAuth):** دکمه‌ی Connect را می‌زند، در ارائه‌دهنده لاگین می‌کند و آدرس بازگشت را در داشبورد paste می‌کند | وضعیت هر اتصال (سبز یا قرمز) و سهمیه‌ی باقی‌مانده | **پرتیکت‌ترین مرحله:** OAuth روی سرور کمی دستی است و راهنمای تصویری لازم دارد |
| **۵. ساخت Combo** | یک زنجیره تعریف می‌کند، مثلاً `coding = Claude اشتراک → GLM → DeepSeek → رایگان` | نام combo به‌عنوان یک «مدل» قابل انتخاب است | قالب‌های آماده‌ی پیشنهادی کمک می‌کنند |
| **۶. ساخت کلید API** | برای هر ابزار یا عضو تیم یک کلید می‌سازد | کلید مخصوص گیت‌وی | – |
| **۷. اتصال ابزارها** | در ابزار، Base URL و کلید را تنظیم می‌کند، مثلاً برای Claude Code: `ANTHROPIC_BASE_URL=https://.../v1`. در Cursor، Cline یا n8n: بخش «OpenAI-compatible» | ابزار مثل قبل کار می‌کند، ولی پشتش گیت‌وی است | راهنمای جدا برای هر ابزار پرکاربرد |
| **۸. استفاده‌ی روزانه** | کار عادی (کدنویسی، چت، ایجنت) | وقتی یک مدل تمام شد، خودکار سراغ بعدی می‌رود و کاربر متوجه نمی‌شود | – |
| **۹. پایش** | داشبورد مصرف را می‌بیند | توکن، هزینه، سهمیه، خطاها، و مصرف به تفکیک کلید و نفر | – |
| **۱۰. نگهداری** | کاری نمی‌کند | به‌روزرسانی، بکاپ و افزایش منابع از پنل | تیم ایران‌سرور ایمیج‌ها را pin و به‌روز می‌کند |

### ب) فلوی اپراتور (ایران‌سرور)
1. ثبت سفارش در پنل → ساخت Application در ArgoCD از قالب Helm یا Kustomize
2. ساخت Secret با رمز اولیه و کلیدهای امضا (تصادفی برای هر مشتری)، PVC، Service، Ingress با SSL، و NetworkPolicy برای بستن دسترسی به شبکه‌ی داخلی
3. Health check و تحویل اطلاعات ورود به مشتری
4. پایش: advisoryهای امنیتی upstream، انتشار نسخه‌ی جدید (pin‌شده) از طریق Git
5. بکاپ دوره‌ای والیوم و پشتیبانی تیکت

### ج) حالت‌های استفاده‌ی نمونه
- **فریلنسر:** Claude Code + Combo «اشتراک → GLM → رایگان» → کدنویسی بی‌وقفه
- **تیم ۵ نفره:** ۵ کلید جدا + کلیدهای API مشترک شرکت → گزارش هزینه‌ی هر نفر
- **n8n:** ورک‌فلوهای AI به گیت‌وی وصل‌اند؛ اگر یک ارائه‌دهنده قطع شود ورک‌فلو نمی‌خوابد. فرصت بسته‌ی «n8n + گیت‌وی» هم همین‌جاست

## ۷. حجم بازار (TAM / SAM / SOM)

**تعریف:** هزینه‌ی میزبانی گیت‌وی مدیریت‌شده برای برنامه‌نویسان و تیم‌های فارسی‌زبان داخل ایران. هزینه‌ی توکن مدل‌ها حساب نشده است.

- **TAM:**
  - بالا به پایین: بازار جهانی LLM Gateway در ۲۰۲۵ بین ۲٫۲ تا ۳٫۳ میلیارد دلار است (Business Research Company، نرخ رشد سالانه حدود ۲۷٪). سهم ایران با در نظر گرفتن قدرت خرید و تحریم حدود ۰٫۰۵ تا ۰٫۱٪ است، یعنی **۱ تا ۳ میلیون دلار در سال**.
  - پایین به بالا: حدود ۱۵۰ تا ۳۰۰ هزار برنامه‌نویس (فرض) × ۶۰٪ که از AI استفاده می‌کنند × ۶۰ دلار در سال = **۵٫۴ تا ۱۰٫۸ میلیون دلار**.
  - جمع‌بندی: حدود **۳ تا ۵ میلیون دلار** (سقف نظری).
- **SAM:** کسانی که ایجنت CLI یا IDE دارند (حدود ۲۵٪)، به مسیریابی چندارائه‌دهنده‌ای نیاز دارند (حدود ۳۰٪) و نسخه‌ی میزبانی‌شده را ترجیح می‌دهند (۱۵ تا ۲۵٪). حاصل: حدود **۱٫۷ تا ۴ هزار نمونه** × ۵ دلار در ماه = **۱۰۰ تا ۲۴۰ هزار دلار در سال**.

  - سال اول: ۵ تا ۱۰٪ از SAM، یعنی **۱۰۰ تا ۳۰۰ نمونه**، حدود **۶ تا ۱۸ هزار دلار در سال**
  - سال سوم: ۲۰ تا ۴۰ هزار دلار با پلن تیمی

- **تیمی و حرفه‌ای:** ۲ تا ۴GB رم یا بیشتر، بکاپ روزانه، دامنه‌ی اختصاصی؛ معادل حدود ۸ تا ۱۵ دلار در ماه

## ۱۰. توصیه‌ها
1. **Beta کم‌هزینه‌ی ۹۰ روزه** با نرم‌افزار انتخاب‌شده برای پلن پایه (9Router) و تنظیمات امنیتی اجباری.
2. **قبل از عرضه، رم واقعی را بسنجید.** 9Router و OmniRoute را یک هفته در staging با یک ایجنت کدنویسی واقعی اجرا کنید و قیمت پلن‌ها را بر اساس عدد واقعی ببندید.
3. **معیار ادامه یا توقف:** کمتر از ۵۰ نمونه‌ی پولی فعال یا ریزش ماهانه‌ی بیشتر از ۲۰٪ یعنی توقف سرمایه‌گذاری بازاریابی.
4. **پیام بدون «رایگان».**
5. **اول فروش افزایشی** به مشتریان فعلی (VPS خارج، n8n).
6. **بررسی تطابق حقوقی** (AUP دیتاسنتر خارجی، و AGPL در صورت انتخاب new-api) قبل از عرضه.
