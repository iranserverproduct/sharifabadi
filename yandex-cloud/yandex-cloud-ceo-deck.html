Object Storage

‫فضای فایل برای بکاپ، عکس، ویدیو و فایل‌های سایت‬

Block Storage

‫• انواع: HDD، SSD، SSD غیرتکراری، SSD پرسرعت‬

‫• ساخت، افزایش حجم، اتصال و حذف با Disk API‬

‫• اسنپ‌شات و زمان‌بندی خودکار اسنپ‌شات‬

در یاندکس، Block Storage محصول جدایی نیست و دیسک‌ها با Compute Cloud مدیریت می‌شوند. در سایت ایران سرور می‌توانیم آن را به‌عنوان «دیسک اضافه» جدا بفروشیم. حداکثر اندازه‌ی یک دیسک ۲۵۶ ترابایت است.
