‫محصول ۷‬

‫Managed Kubernetes: کلاستر آماده برای تیم‌های توسعه‬

‫چه می‌فروشیم‬

‫یاندکس control plane را مدیریت می‌کند؛ مشتری فقط گروه نودها را انتخاب می‌کند.‬

‫وب‌سرویس‬

‫Cluster، NodeGroup، Version و ResourcePreset برای ساخت، مقیاس و حذف‬

‫وابستگی‬

‫نودها ماشین مجازی‌اند و از کوتای Compute همان مشتری مصرف می‌کنند.‬

‫مشتری هدف: استارتاپ‌ها و تیم‌هایی که میکروسرویس اجرا می‌کنند و نیروی DevOps کافی ندارند.‬

هزینه‌ی Kubernetes دو بخش دارد: مدیریت کلاستر (master) و ماشین‌های نودها. برای مشتری‌های Kubernetes احتمالاً باید کوتای Compute بالاتری درخواست کنیم.
