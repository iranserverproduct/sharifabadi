‫Cloud Backup و Smart Web Security‬

Smart Web Security

‫• فایروال وب (WAF)، ضد ربات و محدودیت نرخ درخواست‬

‫• حفاظت دامنه با پروکسی یاندکس، برای سایت‌های خارج از یاندکس هم (Preview)‬

‫• API: SecurityProfile، WAF، ARL‬

Cloud Backup

‫• بکاپ کامل و افزایشی با زمان‌بندی روزانه، هفتگی، ماهانه‬

‫• برای Compute، BareMetal و حتی سرورهای بیرون از یاندکس‬

‫• بازیابی کل سرور یا تک‌فایل‬

‫• API: Policy، Resource، Backup‬

‫فرصت: هر دو محصول را می‌توان به مشتری‌های فعلی ایران سرور هم فروخت برای سرورهایی که مستقیم از خود یاندکس گرفته میشود.‬

Cloud Backup روی ماشین‌ها ایجنت نصب می‌کند (روی Compute خودکار است) و ارائه‌دهنده‌ی فنی آن Cyberprotect است. حفاظت دامنه‌ی Smart Web Security هنوز Preview است و سرور مقصد باید IP عمومی داشته باشد. تأخیر شبکه از ایران تا پروکسی یاندکس باید تست شود.
