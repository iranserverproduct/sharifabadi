‫محصول ۲‬

‫BareMetal: سرور اختصاصی با اجاره‌ی دوره‌ای‬

‫نزدیک به مدل فعلی ما‬

‫تنها محصولی که خود یاندکس دوره‌ی اجاره و تمدید دارد.‬

‫هشدار: API آلفا‬

‫نسخه‌ی v1alpha است و ممکن است تغییر کند. نمایش موجودی واقعی سرورها هم باید تأیید شود.‬

‫متد API‬ ‫اکشن در پنل مشتری‬
Configuration / RentalPeriod‫کاتالوگ کانفیگ‌ها و دوره‌ها‬
CreateServer‫اجاره‌ی سرور‬
BatchCreateServers‫اجاره‌ی چند سرور با هم‬
PowerOn / PowerOff / Reboot‫روشن، خاموش، ری‌بوت‬
ReinstallServer‫نصب مجدد سیستم‌عامل‬
RenewServerRental‫فعال کردن تمدید اجاره‬
DeleteServer‫حذف سرور‬
سرویس‌های دیگر BareMetal API: HardwarePool، Image و BootImage، زیرشبکه‌ی عمومی و خصوصی، VRF و Zone. پیشنهاد می‌شود BareMetal در فاز سوم و بعد از پایدار شدن API عرضه شود.
