‫Folder ها و منابع: سرور، دیسک، باکت‬

‫همه‌ی فروش‌ها در یک اکانت جمع نمی‌شود؛ هر مشتری زیرحساب خودش را دارد.‬

‫کوتا روی Cloud است، نه Folder. پس «پروژه»ی هر مشتری یعنی یک Cloud جدا.‬

‫فاکتور همه‌ی مشتری‌ها یک‌جا برای ایران سرور صادر می‌شود.‬

‫ساخت زیرحساب با API ممکن است. ساخت Cloud و تنظیم کوتا در مستندات از پورتال شریک آمده؛ خودکارسازی کامل را از یاندکس تأیید بگیریم.‬

وقتی زیرحساب ساخته و تأیید شود، یاندکس برای آن یک سازمان جدا با نام For 'Customer_name' subaccount می‌سازد. Cloud مشتری داخل همین سازمان ساخته می‌شود و کوتاهای پیش‌فرض خودش را دارد.
