# فضای کار پروتوتایپ پورتال ایران‌سرور

نسخه‌ی کپی‌شده‌ی پورتال (hub.iranserver.com) با دیتای فیک، به‌همراه فضای کار مدیران محصول: ورود، نقش‌ها، پیشنهاد روی هر روت و ایجنت طراحی.
نسخه‌ی منتشرشده: آرتیفکت «فضای کار پروتوتایپ» در Claude.

## قوانین ثابت
1. فونت فقط پیدا (`fonts/`، تعریف در `fonts.css`).
2. هر تغییر فقط روی همان روت؛ روی بقیه‌ی پروژه اثری ندارد.
3. هسته (هدر، منوها، فوتر، قالب، استایل پایه و این فایل‌ها) فقط با ادمین کل تغییر می‌کند.

## فایل‌ها
| فایل | چیست | چه کسی تغییر می‌دهد |
|---|---|---|
| `index.html` | قالب پروتوتایپ: مسیریابی روت‌ها، منوها، تب‌ها | ادمین کل |
| `ws.js` | فضای کار: ورود، نقش‌ها، پیشنهادها، ایجنت، قوانین ثابت | ادمین کل |
| `pages0-3.js` | صفحه‌های کپی‌شده‌ی پورتال (نسخه‌ی پایه‌ی هر روت) | ادمین کل |
| `extra.js` | منوها، پاپ‌آپ‌های هدر، منوی موبایل، اتصال ردیف‌ها | ادمین کل |
| `new.css`، `legacy.css` | استایل پورتال جدید و پورتال قدیمی | ادمین کل |
| `fonts.css`، `fonts/` | فونت پیدا | ادمین کل |
| `seed_users.json` | کاربران اولیه و روت‌های هر نفر | ادمین کل (از پنل کاربران) |

پیشنهادهای مدیران محصول و روت‌های جدید در این پوشه نیستند؛ در دیتابیس آرتیفکت ذخیره می‌شوند و روی همان روت نمایش داده می‌شوند.

## اجرا روی سیستم
پوشه را دانلود کنید و با یک سرور ساده باز کنید (مثلاً `python3 -m http.server` و بعد `http://localhost:8000`). بیرون از Claude ایجنت در دسترس نیست و داده‌ها فقط در همان مرورگر ذخیره می‌شوند.
