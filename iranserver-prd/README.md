# دستیار PRD ایران‌سرور

ابزار مدیران محصول ایران‌سرور برای نوشتن سند PRD با ساختار ثابت تیم. ایجنت با مدیر محصول گفت‌وگو می‌کند، سؤال می‌پرسد تا اطلاعات کامل شود، بعد سند را می‌نویسد و خروجی گوگل داکس می‌دهد.

| بخش | مسیر |
|---|---|
| ایجنت گفت‌وگومحور (Artifact) | `app/index.html` |
| قابلیت‌های Artifact | `app/capabilities.json` |
| اسکیل Claude Code | `.claude/skills/iranserver-prd/` |

## ایجنت گفت‌وگومحور

نسخه منتشرشده: https://claude.ai/artifact/FRSsi7dY8tSYqnkHKDJc6f

جریان کار:

| مرحله | کاری که انجام می‌شود |
|---|---|
| ۱. گفت‌وگو | ایجنت در هر نوبت یک سؤال می‌پرسد و از پاسخ‌ها خلاصه سند را کامل می‌کند. موارد اجباری: عنوان، مشکل، مخاطب، محدوده، مسیر کاربر، معیار موفقیت. موارد نامعلوم با `[نیازمند تصمیم]` علامت می‌خورند. |
| ۲. خلاصه | وقتی اطلاعات کامل شد، کارت خلاصه و دکمه «نوشتن سند» نمایش داده می‌شود. |
| ۳. نگارش | سند در چهار مرحله با ساختار الگوی تیم نوشته می‌شود: نگاه کلی و بخش‌های ۱ تا ۹. |
| ۴. اصلاح | مدیر محصول تغییر را در پیام می‌نویسد؛ فقط بخش‌های مربوط بازنویسی می‌شوند و نسخه سند بالا می‌رود. |
| ۵. خروجی | ساخت گوگل داکس در درایو همان کاربر، دانلود فایل HTML، کپی متن. |

قابلیت‌های runtime:

| قابلیت | کاربرد |
|---|---|
| `sample` | گفت‌وگو و نگارش با Claude |
| `mcp` (Google Drive، `create_file`) | ساخت خروجی گوگل داکس |
| `downloads` | دانلود فایل HTML |

گفت‌وگو و سند در `localStorage` مرورگر هر کاربر نگه داشته می‌شود و به کاربر دیگر نمی‌رسد.

پیش‌نیازها:

- اکانت سازمانی Claude ایران‌سرور.
- برای خروجی گوگل داکس: اتصال Google Drive در claude.ai › Settings › Connectors.
- هزینه هر سؤال و هر نگارش از سهم استفاده Claude همان کاربر کم می‌شود.

انتشار یا به‌روزرسانی: `app/index.html` را با ابزار Artifact منتشر کنید و محتوای `app/capabilities.json` را به‌عنوان capabilities بدهید. برای به‌روزرسانی، آدرس همان Artifact را بدهید تا لینک حفظ شود. بعد از انتشار، از منوی Share صفحه آن را با مدیران محصول به اشتراک بگذارید.

## اسکیل Claude Code

پوشه `.claude/skills/iranserver-prd` را در `~/.claude/skills/` (برای همه پروژه‌ها) یا `.claude/skills/` یک پروژه کپی کنید و با دستور `/iranserver-prd` اجرا کنید.

## ساختار سند

ساختار سند فقط همان الگوی سند «بکاپ خودکار زمان‌بندی‌شده سرورهای ابری» است (`.claude/skills/iranserver-prd/template.md`). پرامپت‌های ایجنت همین ساختار را دارند؛ اگر الگو تغییر کند، هر دو باید به‌روز شوند.

## محدودیت‌های فعلی

- خواندن کامنت‌های گوگل داکس هنوز پشتیبانی نمی‌شود؛ اصلاحات در همان گفت‌وگو نوشته می‌شوند.
- تست‌نشده: گفت‌وگو، نگارش، خروجی گوگل داکس و دانلود هنوز یک دور کامل داخل claude.ai اجرا نشده‌اند.
