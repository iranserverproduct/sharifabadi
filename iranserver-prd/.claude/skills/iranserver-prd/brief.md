# PRD brief

The smallest input that lets the agent write a good first draft. The user can paste this filled in, in Persian or English. Anything left empty becomes an open question in the PRD.

```
موضوع:            {feature or epic name}
مشکل:             {what is wrong today, for whom, with any evidence}
محدوده:           {what is in this version, and what is left for later}
معیار موفقیت:     {what number or behaviour tells us it worked}
تصمیم‌های قطعی:   {pricing rules, infrastructure decisions, dates already agreed}
تیم‌ها:           {owner, designer, developers, QA, stakeholders}
لینک‌ها:          {current flow URL, WHMCS admin pages, related PRDs, competitor notes}
```
